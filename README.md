# СПОРИМ — API платформы прогнозов

«СПОРИМ» - сервис, где люди делают прогнозы на события. Все ставки идут на виртуальные
баллы, а не на деньги. Пользователи сами создают события, модераторы вручную подтверждают
их и фиксируют результат.

Здесь лежит серверная часть (API). Интерфейс сайта к ней пока не подключён.


## Что уже реализовано

**Пользователи**

- регистрация и вход по логину или почте;
- профиль, баланс баллов, статистика: сколько ставок сделано, сколько выиграно, процент побед;
- при регистрации начисляется 1000 баллов.

**События**

- пользователь создаёт событие и варианты исхода (например, «Да» / «Нет»);
- автор предлагает коэффициент, модератор подтверждает или меняет его при одобрении;
- новое событие попадает на проверку модератору;
- отклонённое событие можно исправить и отправить на проверку повторно;
- лента событий с фильтром по категории, поиском, сортировкой по объёму и фильтром по автору;
- блок «Горячие темы» — топ событий по объёму ставок;
- блок «Интересное» — активные события для карточек;
- 7 стартовых категорий: политика, спорт, криптовалюта, киберспорт, климат, наука, упоминания.

**Ставки**

- ставка «Да» или «Нет» на выбранный вариант;
- баллы списываются сразу, коэффициент фиксируется в момент ставки;
- проценты по вариантам пересчитываются после каждой ставки;
- один человек может поставить на одно событие только один раз;
- в минус уйти нельзя: при нехватке баллов API отвечает `422` с кодом `insufficient_balance`;
- на своё событие ставить нельзя.

**Комбо**

- комбо — одна позиция `YES` или `NO`, собранная из нескольких активных событий;
- сумма списывается один раз, коэффициент входа фиксируется в момент сборки;
- `YES` выигрывает, если выиграли все ноги; `NO` — если проиграла хотя бы одна;
- выплата считается по произведению коэффициентов ног;
- отменённая нога даёт множитель `0.5`, остальные ноги продолжают играть;
- в одном комбо не может быть двух ног на одно событие.

**Модерация**

- модератор видит очередь событий на проверке;
- одобряет событие, при необходимости меняя предложенный коэффициент (допустимый диапазон `1.01–10.0`);
- отклоняет событие с обязательной причиной;
- не может модерировать собственное событие;
- фиксирует победный вариант: выигравшим начисляются баллы, проигравшим нет;
- при отмене события одиночные ставки возвращаются полностью, а ноги комбо получают множитель `0.5`;
- повторная фиксация результата не начисляет выплаты второй раз;
- все действия модераторов записываются в журнал `moderation_log`;
- жалобы пользователей на события и их обработка с указанием решения и комментария.

**Администратор**

- список пользователей с поиском и фильтрами;
- назначение модераторов, блокировка и разблокировка пользователей;
- общая статистика платформы;
- создание, изменение и удаление категорий.

**Безопасность**

- пароли хранятся в зашифрованном виде;
- вход по токенам: короткий рабочий и длинный для продления;
- username уникален без учёта регистра, но сохраняет исходное написание;
- у каждого своя роль: пользователь, модератор, администратор;
- чужой профиль, ставку или комбо посмотреть нельзя — API отвечает `404`;
- в production приложение не стартует с небезопасным секретом, включённым `DEBUG` или `CORS_ORIGINS=*`;
- изображения и источники резолюции принимаются только как `http://` или `https://`.

**Документация и тесты**

- автоматическая документация API со всеми запросами и кнопкой авторизации;
- 58 автотестов: регистрация, ставки, проценты, выплаты, комбо, модерация, видимость, поиск, конфигурация и админка.

## Как запустить

Нужно: Python 3.12 или новее и установленный PostgreSQL.


### 1. Подготовить окружение

```bash
python -m venv .venv
source .venv/Scripts/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 2. Настроить подключение к базе

```bash
cp .env.example .env
SECRET=$(python -c "import secrets; print(secrets.token_urlsafe(32))")
sed -i "s|^SECRET_KEY=.*|SECRET_KEY=${SECRET}|" .env
```

Затем откройте файл `.env` и проверьте строку с адресом базы. Если у вашего PostgreSQL
другой пароль, впишите свой.

### 3. Создать базу данных

```bash
psql -U postgres -c "CREATE DATABASE sporim;"
```

### 4. Создать таблицы

```bash
alembic upgrade head
```

### 5. Заполнить стартовые данные

```bash
python -m app.cli seed-categories
python -m app.cli create-admin --username admin --email admin@example.com --password adminpass123
```

### 6. Запустить сервер

```bash
uvicorn app.main:app --reload
```

Сервер работает, пока открыто это окно терминала. Остановить — `Ctrl+C`.
